HackerTube：别看 YouTube，来看 HackerTube！

HackerTube | Andrej Karpathy | 2026-10-31

那是周五晚上 11 点，我很累，于是打开 YouTube 想看点东西，结果发现映入眼帘的是一整面已经彻底劣化的垃圾内容墙。夸张到离谱的缩略图、对那些老掉牙话题的愚蠢推荐、真正堪称“白痴文化”级别的糟糕内容。我相信这个算法对互联网上的普通中位数用户来说运作得很好，但它显然不适合我。所以今天早上（周六），我叫来了我的 Opus 5.5，给了它一个任务：我们来写一个自己的 YouTube 克隆版，内容来源就基于 Hacker News 上推荐过的视频。然后 Opus 给我带回来了这个：hackertube.org！

Opus 下载了 HackerNews 的所有评论，对其进行了筛选，并在一个 Workflow（Claude Code 的功能）里跑了 Sonnet，去除了垃圾内容，最终将范围缩小到 4 万条推荐 YouTube 视频的评论。总共我们得到了 6,454 个 YouTube 视频，它们是在 2007-2026 年间由 HN 上的一些用户推荐的，覆盖 150 个主题。然后我们再把这些内容包上一层 YouTube 风格的 UI，弄个域名，部署到 VPS，上安全措施、做加固、做优化，大功告成！

HackerTube：

  • 包含高质量内容
  • 使用视频 50% 进度处的画面作为缩略图，而不是上传者设置的缩略图
  • 提供自定义且优质的 ForYou 推荐，无需任何用户账号，状态保存在本地浏览器会话中
  • 支持键盘快捷键
  • 提供站点数据导出，你可以把它交给自己的智能体，轻松创建你自己的版本

现在这件事大约只需要 ~2 小时。我终于又能顺畅呼吸了。谢谢你，Opus 5.5 <3。

编辑：再稍微补充一点我的流程。我使用的是 Claude Code（Mac 桌面应用）。我默认使用 Medium effort 模式下的 Opus 5.5。现在我实际上已经不再 做 任何接近传统工程的事情了（读/写代码、在终端里运行命令，诸如此类），我只需要和 Claude 对话，让它把一切都做完。在这个例子里，我唯一做的“手工活”是：1）我得在 Google Cloud 的界面里创建某种 API key，用来查询 YouTube 的视频元数据；2）我启动了一台 VPS；3）我买了这个域名。我是在 Claude 真正干活的间隙处理这些事情的，所以这多少还是有点像团队合作 :) 等服务器起来之后，我把 IP 给了 Claude，告诉它去更新、部署、加固安全、强化并优化代码，然后它就把整件事都完成了。
